### Project Status

Approximately **~50%** complete. Frontend and AI logic are working; full backend integration is in progress.

###  Goal and Description

The project is **educational**: I wrote it to study MCP-server architecture in practice.

###  Technical Implementation

The server is written in **Python** and communicates via **stdio**. It provides models with context without compromising system security.

##### **Main Features:**

- **Semantic Map:** AI understands the project structure, sees entry points in Rust, Python, and frontend.
- **Smart Navigation:** Reading files, searching code, and building a directory tree.
- **Fixes:** AI suggests patches and refactoring.
- **Git Analysis:** Reads repository history and status to understand current progress.
